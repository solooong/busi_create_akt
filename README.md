
# Парсер ДДУ и генератор актов приёма-передачи

Скрипт для автоматического извлечения данных участников долевого строительства из PDF-документов (Договор долевого участия) и заполнения актов приёма-передачи квартир.

## Возможности

- Поиск и распаковка ZIP-архивов с документами (глубина вложенности до 2 уровней)
- Извлечение данных участников из PDF:
  - ФИО, дата рождения, паспортные данные, адрес
  - Контактные данные (телефон, email, ИНН, СНИЛС)
  - Реквизиты договора (номер, дата, кадастровый номер)
  - Характеристики квартиры (номер, этаж, площадь)
- Поддержка нескольких участников в одном договоре
- Сохранение результатов в Excel (.xlsx)
- Автоматическое заполнение актов приёма-передачи (.docx) по шаблону

## Требования

- Python 3.8 или выше
- Установленные библиотеки:

```bash
pip install pdfplumber openpyxl python-docx
```

## Быстрый старт

### 1. Подготовка данных

Поместите ZIP-архивы с документами в корневую папку или подпапки (до 2 уровней вложенности).  
Файлы должны содержать PDF с триггерами в названии: `ДДУ`, `Договор долевого участия`.

### 2. Создание шаблона акта

Создайте файл `template_akt.docx` в Microsoft Word. Расставьте плейсхолдеры в нужных местах:

```
{{ФИО}}
{{дата_рождения}}
{{паспорт}}
{{адрес_проживания}}
{{телефон}}
{{email}}
{{договор_№}}
{{дата_договора}}
{{номер_квартиры}}
{{этаж}}
{{общая_площадь}}
{{жилая_площадь}}
{{адрес_строительства}}
...
```

**Важно:** названия плейсхолдеров должны точно совпадать с заголовками выходной Excel-таблицы.

### 3. Запуск

```bash
python main.py "путь/к/папке/с/архивами"
```

Если путь не указан, используется текущая папка.

### 4. Результаты

- **Excel-файл** `participants_YYYY-MM-DD_HH-MM-SS.xlsx` — все извлечённые данные
- **Акты приёма-передачи** в папке `Акты/` — по одному файлу `.docx` на каждого участника


## Логирование

Логи сохраняются в файл `processing.log` и выводятся в консоль.

## Решение проблем

### "Не найдено 'Устава, и'"
PDF-файл имеет нестандартную структуру шапки. Проверьте, что документ является договором долевого участия.

### "Раздел 'Участники долевого строительства' не найден в реквизитах"
Контакты извлекаются с последних страниц. Убедитесь, что в PDF есть раздел с реквизитами сторон.

### "Ни одного участника не извлечено"
- Проверьте, что PDF содержит текст (не сканированная копия)
- Убедитесь, что в имени файла есть триггеры (`ДДУ`, `Договор долевого участия`)
- Исключены файлы `.sig` и другие не-PDF

## Масштабирование

Для добавления новых форматов документов:
1. Создайте новый класс-парсер, наследующий `BaseParser`
2. Добавьте его в `main.py` по аналогии с `DDUParser`
